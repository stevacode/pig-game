# Pig Game

This project is a JavaScript course project: a simple two-player dice game built with vanilla JavaScript.

## How it works

- Players take turns rolling a die.
- Each roll adds to the current score unless the player rolls a 1.
- A player can click "Hold" to save the score and pass the turn.
- The first player to reach 100 points wins the game.

## Run locally

Open `index.html` in your browser.
